# prisha-personal-website

Personal website for Prisha Agarwal. Editorial, calm, typographically driven. Not a portfolio template.

## Stack

- Astro 7 (static output, no client framework; small vanilla `<script>` islands only)
- Fonts self-hosted via Fontsource: Fraunces Variable (display), Newsreader Variable (body), IBM Plex Mono (labels)

## Commands

- `npm run dev` — dev server at http://localhost:4321
- `npm run build` — static build to `dist/`
- `npm run check` — astro check (types + diagnostics); run this plus `npm run build` before considering work done
- Visual review: `agent-browser` is installed globally (`agent-browser open <url>`, `set viewport 390 844`, `set media dark|light [reduced-motion]`, `hover <sel>`, `screenshot /abs/path.png`). Use absolute paths for screenshots. Check light + dark, 390px, and reduced motion for anything scroll-driven

## Architecture

- `src/data/sections.ts` — single source of truth for the 6 numbered sections (nav, menu, homepage index all derive from it; the footer is 07). "What I build" was removed deliberately — don't add a projects section back
- `src/data/chain.ts` — the moments of "How one thing led to another" (markets → the filings → the anchoring study → HDFC → the tab problem → teaching, as a "meanwhile" aside → UAA, last): vine connector words, headings, details with marked terms, and the evidence each term reveals (`clippings` / `cascade` / `ledger` / `tabs` / `window`). Copy lives here, not in the component. Every fact matches `/conventional`; the moments are the story's connective tissue, not résumé bullets — keep them concrete, no abstract "curiosity" filler, no punchline per stop. UAA deliberately ends the page: it is unreleased, has no page, demo, or deck, and must never grow a CTA — the `window` evidence (the thought bubble's tabs settled into one hairline frame) is the whole payoff
- `src/components/Chain.astro` — the vine. One SVG generated at runtime from where the text actually lands (centripetal Catmull-Rom through per-moment anchors; a prolate-cycloid curl on the first crossing; a superellipse outline for the thought bubble whose roundness adapts so text never touches it). The geometry is data-driven: any number of alternating `left`/`right` spine moments, exactly one `thought`, then one or more `close` moments; sibling CSS (`.place-left ~ .place-left` etc.) shifts repeat placements a column so nothing lands twice, and evidence panels open toward whichever side of the page the moment left empty. Drawn by scroll from a single smoothed "tip" at 62% of the viewport; moments and labels light when the tip passes them and stay lit. Evidence opens on hover, click/tap, Enter/Space; Escape closes — except `tabs` (partly open once lit) and `window` (static in the body, items fading in after the moment lights; no trigger). Under 960px it collapses to one column and hover evidence unfolds in place. Product/CTA support was removed on purpose — don't add link buttons to moments
- `/uaa` and `/building` no longer exist (removed Sept 2026, with "What I build" cut from the index). UAA is not deployed and has no deck; it appears only as the final chain moment (`/one-thing-led-to-another#uaa`, which Now and `/conventional` link to). Don't recreate a projects page, product page, or "coming soon" CTA
- `src/data/now.ts` — everything on the Now page: dateline, in-progress items, and the current semester's courses (title + dept; `note` only where it adds something; `tentative: true` adds the dagger + footnote)
- `src/components/Semester.astro` — the semester board on Now: a plain two-column grid, no group labels. Renders whatever `now.ts` contains
- `src/data/trail.ts` — the Academic Trail (`/academic-trail`, reached from Now, not in the section index). A flat list of courses in page order; `term` and `note` optional. Real relationships between courses are stated in notes, not drawn — deliberate: an earlier version classified waypoints (stops/spurs/clearings, trailhead sign, disputed links) and was cut for over-explaining
- `src/components/Trail.astro` — the trail's line. One dashed Catmull-Rom line, computed from real DOM positions, runs down each course's left margin and swings across in the space between — a guide for the eye, not a diagram; it never touches a course. The walker (the site's Mark) rolls along it by scroll (length from a running-max-y table at 62% viewport, same feel as the vine); walked distance inks the line via a growing clip, and courses fade from 0.3 to full as it passes. Courses alternate sides with a stagger; under 900px everything sits beside a single left rail. Reduced motion: line fully inked, walker hidden
- `src/data/books.ts` — the Elsewhere bookshelf: two shelf arrays of books (title, author, cover import, `size` for standing height, optional `tilt`). Covers are local JPEGs in `src/assets/books/`, sourced once from the Open Library covers API — no external hotlinks
- `src/components/Bookshelf.astro` — two physical ledges. Books stand at real cover aspect ratios (height set, width auto — never distorted). Hover/focus pulls a book toward the viewer (`perspective()` translate3d + rotateY, neighbors part 4px via `:has`); click picks it up: a FLIP flight (WAAPI) from the shelf slot to a fixed centered stage, leaving a visible gap on the shelf, with the page veiled but present behind. Put back = click book/veil/"Put it back"/Escape → it flies back into its gap; focus returns to the shelf button. Under 1020px the shelves pan horizontally (books keep full size); reduced motion keeps every interaction with zero-duration flights. Scroll locks while a book is held via `:root.holding-book`
- `src/data/conventional.ts` — the professional record behind `/conventional`, taken off the résumé of record (Sept 2026): education (Barnard/Columbia, Oberoi, Ashoka YSP), experience (HDFC AMC, Columbia Math TA, Scarecrow M&C Saatchi), research & building (UAA, economics research, this site), community, skills. Every fact must be true; nothing is bracketed at the moment, but the `{ text, tk: true }` slot mechanism remains for unconfirmed values (renders bracketed in mono) — never let invented credentials in. HDFC and UAA are deliberately the longest entries: `lead` + several `details`, plus `figures` (HDFC) and `breakdown` rows (UAA). Phone number is intentionally omitted from the public page
- `src/components/Dossier.astro` — the conventional version as a dossier: a sticky typographic cover (name, index, linked contacts, Print) beside a ruled ledger document on a wider-than-usual container (92rem). The site's Mark travels the cover index as a cursor tracking the active section (recomputed from a 42% reading line on scroll — no IO races); visited sections stay marked. Entries settle in with staggered reveals; section rules ink in. Under 880px the cover collapses and a sticky mono strip tracks the active section. Includes a print stylesheet — the PDF résumé is a byproduct of the page (Print button → window.print())
- `src/data/contexts.ts` — the Context page lenses: Academic, New Yorker, Analyst, Foodie, plus the control. Each has an image "plate" in `src/assets/context/` (`portrait.jpg`, `student.jpg`, `newyork.jpg`, `markets.jpg`, `foodie.png`), crossfaded in `ContextExplorer.astro`. Persona lenses from older concepts (Coder, Investor, and any annotation-overlay lens) are retired — do not reintroduce them; the `annotations` mechanism in the component is dormant on purpose. The stage is a mounted print: hairline frame + narrow `bg-raised` mat around a 4/5 plate box, and lens changes get a brief projector blink (`is-advancing`) plus a scale-settle on the incoming plate; both are killed by reduced motion. `portrait.jpg` is the full, uncropped original upload — its framing is intentionally left alone (no crop/zoom) since that caused a visible jump between lenses before. Student/New York are separate generated images and are known not to be pixel-identical to the original; that inconsistency is accepted rather than "fixed" with further cropping
- `src/pages/index.astro` — the homepage carries the site's opening gesture: a thread in the vine's stroke language, drawn at runtime from real offsets (name → down the empty right margin → back across to the index), driven by the same 62%-viewport tip/running-max-y technique as Chain/Trail, ending in a three-stroke asterisk before "The index" (the "you are here" mark). Anchors are measured with offset chains, not client rects, so the reveal/rise transforms can't skew it; hidden under 960px; reduced motion gets it fully drawn. The intro rises in on load (label → h1 → copy), and the index rows stagger on reveal
- `src/layouts/Base.astro` — head, theme init (inline, pre-paint), reveal-on-scroll observer, header/menu/footer. The menu overlay shows each section's blurb (from `sections.ts`), with the active row swapped to "you are here" + the Mark
- `src/styles/global.css` — all design tokens (colors, type scale, motion durations/easings). Both themes defined here; `data-theme` on `<html>`
- Theme switch uses the View Transitions API for a circular reveal from the toggle button; falls back to instant switch (reduced motion / unsupported browsers)
- Scroll reveals: put `data-reveal` on an element; CSS handles the rest (gated behind `.js` class and `prefers-reduced-motion`)

## Conventions

- Editorial voice: dry, specific, first person. No corporate language ("passionate", "journey", "leverage", "impact")
- Humor comes from understatement and specificity, never engineering. Banned habits (removed once already; don't reintroduce): hedge-winks ("of sorts", "for now", "I'm told there are…"), staged fragments as punchlines ("Both are plausible."), self-aware narrator lines ("None of it is staged"), metaphors that run across pages (the furnishing/house conceit), and em dashes used as joke scaffolding. One idea per line; plain is better than clever
- Never invent biographical facts. Placeholders must be clearly identifiable (see `Scaffold.astro` usage on stub pages)
- Mono uppercase labels for structure ("03 / 07"), Fraunces for display, Newsreader for running text
- Hover states stay subtle: a few px of movement, color shifts, drawn underlines. Nothing theatrical
- Section numbering 01–07 is load-bearing (07 is the footer; the joke is intentional). "Things I'm trying to understand" and "What I build" were deliberately deleted — don't reintroduce a thesis/philosophy section or a projects page
